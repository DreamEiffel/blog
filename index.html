GitLab PAT 过期致 HTTP Basic Access denied 排查

2026-11

HTTPS push 报 Access denied 且密码正确时先查 PAT 是否到期；重生成 token 后须同步更新系统凭据管理器缓存。

PowerShell 5.1 超 260 字符路径静默假阴性

2026-11

超 260 字符路径的 cmdlet 静默返回空导致误判文件不存在；用 robocopy 校验或相对路径规避，先怀疑路径长度再怀疑权限。

字段恒 null：双变更叠加无写入者模式与分层修复

2026-11

两历史变更各废一半写入路径叠加，字段恒 null 且无报错；定位搜写入点 + git 追溯，修复用「结构化新鲜值 > 协议行倒序 > 旧台账」分层优先级。

存量测试失败归因法：clean HEAD 对比

2026-11

全量测试红灯先在干净 HEAD（stash 基线）重跑对比：基线也败的是存量（登记放行），仅本次败的才是引入；逐条留基线证据，不可凭印象。

未跟踪新文件被已提交代码引用致运行时白屏

2026-11

新建文件未随批提交而代码已引用——本地正常、干净环境模块解析失败白屏；提交前核对 git status 新增文件，新组件与引用同批提交。

Vue3 setup 模板访问 Pinia computed 必须 storeToRefs 解包

2026-08-20

模板报 undefined.xxx 时根因常是 store computed 未解包到 setup 本地变量；模板编译只识别 setup 顶层声明，审计模板所有裸名 ref。
